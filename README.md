# Swing Salvage

Fırtınada helikopterle kargo kurtarma: tek parmak, sallanan halat, yalpalayan gemi, tek hata = oyun biter.

- **Nasıl kurulur:** `docs/PROMPTS.md`. Claude Code'a sırayla verilecek 9 faz promptu ve senin yapacakların burada.
- **Oyun tasarımı (tek doğruluk kaynağı):** `docs/GDD.md`
- **Görsel hedef:** `docs/art/mockup-b.html` (tarayıcıda aç)
- **Claude Code kuralları:** `CLAUDE.md`, izinler `.claude/settings.json`

## Durum
v1.0.0 — 9 faz tamamlandı. Web: `npm run dev`, test: `npm test`, Android: `npm run android:sync`. Yayın adımları `docs/RELEASE.md`'de. Kararlar `docs/DECISIONS.md`'de.
